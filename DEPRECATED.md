# DEPRECATED

`zap-es` (a capnp-es fork) is superseded by **`@hanzo/zap`** (`../zap-ts`), the
native ZAP TypeScript runtime — zero dependencies, zero Cap'n Proto, byte-compatible
with `github.com/zap-proto/go` and the `luxfi/zap` transport. New code MUST use
`@hanzo/zap`. Console no longer imports `zap-es`.
